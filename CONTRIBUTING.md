# Contributing

TinyLM is experimental and designed for ESP8266. Read the architecture, developer
guide and roadmap. Discuss large model, protocol or hardware changes in an issue.

1. Fork and create a focused topic branch.
2. Preserve copyright/licenses. Submit only material you may distribute. Document
   external datasets, dependencies and preprocessing changes.
3. Run relevant checks. Report board/core configuration and which hardware tests
   ran, failed or were not available.
4. Update guides, model card, evaluations and changelog when behavior changes.
5. Redact paths, credentials, tokens and unrelated personal data in attachments.
6. Open a pull request describing the problem, resulting behavior and validation.

Original code contributions use Apache-2.0 unless a component states otherwise.
Contributors retain copyright; no transfer or CLA is required. Third-party
components retain upstream terms. The maintainer reviews changes; acceptance,
future support and timelines are not guaranteed. Contributions are voluntary
and free. See CODE_OF_CONDUCT.md and SECURITY.md.

otherwise. Preserve LICENSE and NOTICE; mark modified files when required.
