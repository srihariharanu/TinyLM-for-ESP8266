## Assets and current use

| Asset | Purpose |
| --- | --- |
| [Wide banner](assets/tinylm-banner.png) | Main GitHub README header |
| [Square chip/brain logo](../../firmware/tinylm-logo.png) | Source and ready-to-flash firmware guide headers |

Both PNGs are reproduced byte-for-byte as supplied, retaining their proportions,
colors and text. Markdown/HTML sets the display width without changing the files.
No original image filenames or local upload paths are included in the public docs.

These are documentation assets. They are not compiled into the ESP8266 image,
do not increase flash/RAM use, and do not add a network dependency to the offline
chat page. A downloaded guide can display the bundled logo locally.
The banner identifies the project as experimental for ESP8266; the documentation
continues to state the tested hardware and model limitations.

For future project pages, presentations and release documentation, use the wide
banner for headers and the square image for project identity where space is narrow.
Keep aspect ratio and avoid stretching, recoloring or placing text over the artwork.
